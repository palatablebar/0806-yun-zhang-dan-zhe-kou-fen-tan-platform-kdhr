# 云账单折扣分摊台

云财务月结专员可在工作台上传来源 CSV，对照规则判断差异，签发合格批次或记录暂缓意见。

共享折扣按有效用量分摊，余分按余数和稳定键补齐。

每月关账后，上一账期未用的账户折扣额度（账户额度 − 已签发分摊）结转到下月，形成下月可签发批次与逐户结转依据。补录只改写未签发批次，已关账账期保持可追溯；任一账户超额或额度缺失时整批阻断，下月批次要么完整生效要么保持原样。

## 启动

```sh
docker compose up --build -d --wait
```

打开 <http://localhost:18300>。页面预览带异常样例。选中阶段查看计算证据，选择可签发样例并执行批次，然后提交复核意见。

## 核验

docker compose exec -T app pytest -q
