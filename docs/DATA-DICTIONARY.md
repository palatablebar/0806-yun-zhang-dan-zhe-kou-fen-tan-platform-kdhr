# 字段与业务定义

输入编码 UTF-8，允许 BOM。首行必须匹配样例列顺序。记录键和业务组保留原始字符串。`kind` 允许 usage, pool。说明列 `note` 可以跨行，限制 200 字。

业务字段按 `usage_units`、`discount_cents`、`cap_cents` 排列。数字接受非负整数、全角数字和完整千分位。空串、短横线、N/A、NULL 与未知为缺值。无关字段用 0 占位。

金额以分为最小单位。归集正用量，以最大余额法补齐尾分。同余数时按记录键排序。账户额度不足退回复核。

`incoming.csv` 包含四个业务组，第二组提供不同边界，第三组触发业务拒收，第四组需要核对。另含重复表头、冲突记录、重复回放与错误列数。`ready.csv` 含可以签发的两个组。

## 结转与补录

执行批次时计算结果额外冻结逐户台账 `measure.ledger`：每条含 `record`、`case`、`usage_units`、`cap_cents`（账户额度）、`issued_cents`（已签发分摊）、`carry_cents`（结转额 = 额度 − 已签发）与 `basis`（原账期依据键）。`measure.pool` 冻结折扣池额度。关账后该快照即结转依据，不随后续补录改写。

`supplement.csv` 复用同一 CSV 表头。其中与关账运行逐户相同的记录按已核对重复回放处理（保留一条、标记待补）；新增业务组与账户并入下月批次。缺额度（缺测 sentinel）的账户在采信阶段隔离并以 `CAP_MISSING` 阻断，补全后阻断解除；只有用量没有折扣池的业务组以 `POOL_MISSING` 阻断。
